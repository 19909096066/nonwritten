# Tabbar图标说明

此目录用于存放底部导航栏图标。

## 需要的图标文件

请准备以下6个图标文件（建议尺寸：81x81px，PNG格式）：

1. **home.png** - 首页图标（未选中状态，灰色）
2. **home-active.png** - 首页图标（选中状态，蓝色 #3b82f6）
3. **search.png** - 查询图标（未选中状态，灰色）
4. **search-active.png** - 查询图标（选中状态，蓝色 #3b82f6）
5. **record.png** - 记录图标（未选中状态，灰色）
6. **record-active.png** - 记录图标（选中状态，蓝色 #3b82f6）

## 图标设计建议

- **风格**：简约、扁平化
- **颜色**：
  - 未选中：#7A7E83（灰色）
  - 选中：#3b82f6（蓝色）
- **尺寸**：81x81px（推荐）
- **格式**：PNG（支持透明背景）

## 图标资源网站

可以从以下网站下载或定制图标：

- [iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
- [Flaticon](https://www.flaticon.com/) - 免费图标资源
- [IconPark](https://iconpark.oceanengine.com/) - 字节跳动图标库
- [Feather Icons](https://feathericons.com/) - 简约线性图标

## 使用方法

1. 将准备好的图标文件放入此目录
2. 确保文件名与上述列表完全一致
3. 重新编译项目即可生效

## 临时方案

如果暂时没有图标，可以：
1. 使用emoji表情作为临时图标（已在页面中使用）
2. 或者使用纯色方块作为占位符
3. 后续再替换为正式图标

注意：在pages.json中配置的图标路径必须存在，否则可能导致编译错误。
