# PDA设备部署指南

## 📱 PDA设备说明

PDA（Personal Digital Assistant）是工业级手持终端设备，通常用于仓库管理、物流配送等场景。本系统的移动端应用非常适合在PDA设备上运行。

### PDA设备特点

- ✅ 内置扫码枪（一维码/二维码）
- ✅ 工业级防护（防摔、防水、防尘）
- ✅ 长续航电池
- ✅ Android操作系统
- ✅ 适合仓库等工业环境

## 🎯 部署方案

### 方案1：打包成Android App（推荐）⭐

将Uniapp项目打包成Android APK，安装到PDA设备上运行。

**优点**：
- 性能最好
- 可以离线使用部分功能
- 完美支持PDA扫码枪
- 用户体验最佳

### 方案2：使用浏览器访问H5版本

在PDA设备的浏览器中访问H5版本。

**优点**：
- 无需安装
- 更新方便

**缺点**：
- 扫码功能可能受限
- 性能不如原生App

## 📦 打包Android App

### 方法1：HBuilderX云打包（推荐）

#### 步骤1：配置manifest.json

1. 在HBuilderX中打开 `mobile-app` 项目
2. 打开 `src/manifest.json`
3. 点击"App常用其他设置"
4. 配置以下信息：

```json
{
  "name": "无纺布原材料管理",
  "appid": "__UNI__YOUR_APP_ID",
  "description": "无纺布原材料管理系统移动端",
  "versionName": "1.0.0",
  "versionCode": "100",
  "app-plus": {
    "modules": {
      "Barcode": {
        "description": "扫码功能"
      },
      "Camera": {
        "description": "相机功能"
      }
    },
    "distribute": {
      "android": {
        "permissions": [
          "<uses-permission android:name=\"android.permission.CAMERA\"/>",
          "<uses-permission android:name=\"android.permission.INTERNET\"/>",
          "<uses-permission android:name=\"android.permission.ACCESS_NETWORK_STATE\"/>",
          "<uses-permission android:name=\"android.permission.WRITE_EXTERNAL_STORAGE\"/>",
          "<uses-permission android:name=\"android.permission.READ_EXTERNAL_STORAGE\"/>"
        ],
        "minSdkVersion": 21,
        "targetSdkVersion": 30
      }
    }
  }
}
```

#### 步骤2：执行云打包

1. 在HBuilderX菜单栏选择：**发行** → **原生App-云打包**
2. 选择打包平台：**Android**
3. 选择打包类型：
   - 测试版：使用DCloud公共证书
   - 正式版：使用自有证书
4. 点击"打包"按钮
5. 等待打包完成（通常5-10分钟）
6. 下载生成的APK文件

#### 步骤3：安装到PDA

1. 将APK文件传输到PDA设备
   - 方法1：通过USB数据线传输
   - 方法2：通过微信/QQ发送到PDA
   - 方法3：上传到服务器，PDA浏览器下载
2. 在PDA上点击APK文件
3. 允许安装未知来源应用
4. 完成安装

### 方法2：本地打包（高级）

需要配置Android开发环境，适合有开发经验的用户。

#### 环境要求

- Android Studio
- JDK 1.8+
- Android SDK
- Gradle

#### 打包步骤

```bash
# 1. 构建App资源
cd /workspace/app-9s1afi57chs1/mobile-app
pnpm build:app

# 2. 使用Android Studio打开生成的Android项目
# 3. 连接PDA设备或使用模拟器
# 4. 点击Run按钮或执行：
./gradlew assembleRelease

# 5. 生成的APK位于：
# app/build/outputs/apk/release/app-release.apk
```

## 📲 PDA扫码枪集成

### Uniapp扫码API

Uniapp提供了统一的扫码API，自动适配PDA设备的扫码枪：

```javascript
// 在页面中调用扫码
uni.scanCode({
  success: function (res) {
    console.log('扫码结果：' + res.result);
    // 处理扫码结果
  },
  fail: function (err) {
    console.error('扫码失败：', err);
  }
});
```

### PDA扫码枪适配

大多数PDA设备的扫码枪会自动被Uniapp识别，无需额外配置。

**支持的PDA品牌**：
- ✅ 新大陆（Newland）
- ✅ 霍尼韦尔（Honeywell）
- ✅ 斑马（Zebra）
- ✅ 优博讯（Urovo）
- ✅ 东集（Seuic）
- ✅ 销邦（Supoin）
- ✅ 思必拓（Cilico）

## 🔍 常见问题

### Q1: PDA扫码枪无法使用？

**解决方案**：

1. **检查权限**：确保授予了相机权限
2. **检查扫码枪设置**：
   - 进入PDA系统设置
   - 找到扫码枪设置
   - 确保扫码枪已启用
3. **使用软件扫码**：如果硬件扫码枪不可用，使用相机扫码
4. **联系厂商**：某些PDA需要特殊配置

### Q2: App安装失败？

**解决方案**：

1. **允许未知来源**：
   - 设置 → 安全 → 允许安装未知来源应用
2. **检查Android版本**：
   - 需要Android 5.0（API 21）或更高版本
3. **存储空间**：
   - 确保有足够的存储空间（至少50MB）
4. **重新下载APK**：
   - APK文件可能损坏

### Q3: 无法连接服务器？

**解决方案**：

1. **检查网络**：
   - 确保PDA已连接WiFi或移动网络
   - 尝试在浏览器中访问网站
2. **检查防火墙**：
   - 公司网络可能限制访问
   - 联系IT部门开放Supabase域名
3. **检查配置**：
   - 确认Supabase URL配置正确

### Q4: 扫码后无反应？

**解决方案**：

1. **检查二维码格式**：
   - 确保二维码符合系统规范
   - 格式：`批次号-包号~单位~日期~重量~型号`
2. **查看控制台日志**：
   - 使用HBuilderX真机调试查看错误信息
3. **网络延迟**：
   - 检查网络连接速度

### Q5: 数据不同步？

**解决方案**：

1. **检查登录状态**：
   - 确保已登录
   - 重新登录试试
2. **检查权限**：
   - 确保用户有相应的操作权限
3. **查看操作记录**：
   - 在"操作记录"页面查看本地记录
   - 确认操作是否成功
