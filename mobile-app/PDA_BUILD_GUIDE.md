### 方法1：HBuilderX云打包（推荐）

#### 步骤1：打开项目
1. 启动HBuilderX
2. 文件 → 打开目录

2. 或右键项目 → **发行** → **原生App-云打包**

#### 步骤3：配置打包选项

**打包平台**：
- ✅ 勾选 **Android**
- ⬜ 不勾选 iOS（如果不需要）

**打包类型**：

**测试版（推荐新手）**：
- 选择：**使用DCloud公共证书**
- 优点：无需配置证书，快速打包

- 适用：正式发布

- ⬜ 广告标识（OAID）- 不需要

- ⬜ 自定义基座 - 不需要

2. 等待打包队列

1. 打包完成后显示下载链接

## 🔐 证书管理（正式版）

### 生成Android证书

如果需要打包正式版，需要生成证书：

#### 使用HBuilderX生成
1. 菜单：**发行** → **原生App-云打包**
2. 点击"证书管理"
3. 点击"生成证书"
4. 填写信息：
   - 证书别名：material-management
   - 密码：设置一个强密码
   - 组织：公司名称
   - 城市、省份、国家
5. 点击"生成"
6. 保存证书文件（.keystore）

#### 使用命令行生成
```bash
keytool -genkey -v -keystore material-management.keystore \
  -alias material-management \
  -keyalg RSA -keysize 2048 -validity 10000
```

### 证书使用
1. 在打包时选择"使用自有证书"
2. 上传证书文件
3. 输入证书密码和别名
4. 开始打包

### ⚠️ 证书安全
- 妥善保管证书文件
- 记住证书密码
- 不要泄露给他人
- 定期备份

## 🔄 版本更新

### 更新流程

1. **修改版本号**
   - 编辑 `manifest.json`
   - 修改 `versionName` 和 `versionCode`
   ```json
   {
     "versionName": "1.0.1",  // 显示版本
     "versionCode": "101"     // 内部版本号（必须递增）
   }
   ```

2. **重新打包**
   - 按照上述步骤重新打包
   - 生成新的APK

3. **分发更新**
   - 通知用户下载新版本
   - 或使用自动更新机制

### 版本号规则

```
versionName: 主版本.次版本.修订版本
- 1.0.0 - 初始版本
- 1.0.1 - 修复bug
- 1.1.0 - 新增功能
- 2.0.0 - 重大更新

versionCode: 整数，每次递增
- 100 - 对应 1.0.0
- 101 - 对应 1.0.1
- 110 - 对应 1.1.0
- 200 - 对应 2.0.0
```

## 🐛 常见打包问题

### 问题1：打包失败

**原因**：
- manifest.json配置错误
- 网络问题
- 证书问题

**解决**：
1. 检查manifest.json语法
2. 检查网络连接
3. 重新生成证书

### 问题2：APK无法安装

**原因**：
- Android版本过低
- 证书不匹配（覆盖安装）
- APK损坏

**解决**：
1. 检查PDA的Android版本（需要5.0+）
2. 卸载旧版本后重新安装
3. 重新下载APK

### 问题3：安装后闪退

**原因**：
- 权限未授予
- 配置错误
- 兼容性问题

**解决**：
1. 授予所有必要权限
2. 检查Supabase配置
3. 查看崩溃日志
