# PDA快速部署指南

## 🎯 三步部署到PDA

### 第一步：打包APK

#### 使用HBuilderX云打包（最简单）

1. **打开项目**
   ```
   在HBuilderX中打开：mobile-app 目录
   ```

2. **开始打包**
   ```
   菜单栏 → 发行 → 原生App-云打包
   ```

3. **选择配置**
   - 打包平台：勾选 **Android**
   - 打包类型：选择 **使用DCloud公共证书**（测试用）
   - 点击"打包"按钮

4. **等待完成**
   - 等待5-10分钟
   - 打包成功后会显示下载链接
   - 下载APK文件到电脑

### 第二步：传输到PDA

#### 方法1：USB数据线（推荐）

```bash
# 1. 用USB线连接PDA和电脑
# 2. PDA上选择"文件传输"模式
# 3. 在电脑上打开PDA存储
# 4. 将APK文件复制到PDA的Download文件夹
```

#### 方法2：微信/QQ传输

```
1. 在电脑上通过微信/QQ发送APK文件
2. 在PDA上登录微信/QQ
3. 接收并保存APK文件
```

#### 方法3：二维码下载

```
1. 将APK上传到服务器
2. 生成下载链接的二维码
3. PDA扫码下载
```

### 第三步：安装运行

1. **在PDA上找到APK文件**
   - 打开文件管理器
   - 进入Download文件夹
   - 找到刚才传输的APK文件

2. **安装应用**
   - 点击APK文件
   - 如果提示"不允许安装未知应用"：
     - 点击"设置"
     - 开启"允许安装未知应用"
     - 返回继续安装
   - 点击"安装"按钮
   - 等待安装完成

3. **打开应用**
   - 点击"打开"按钮
   - 或在桌面找到应用图标点击

4. **授予权限**
   - 允许访问相机（扫码功能需要）
   - 允许访问存储（缓存数据需要）

5. **登录测试**
   ```
   手机号：19909096066
   密码：admin123
   ```

6. **测试扫码**
   - 点击"扫码入库"
   - 按PDA上的扫码按钮
   - 扫描测试二维码

## ✅ 完成！

现在可以在PDA上使用应用了！

## 🔧 常见问题快速解决

### 问题1：无法安装APK

**解决**：
```
设置 → 安全 → 允许安装未知来源应用 → 开启
```

### 问题2：扫码枪不工作

**解决**：
```
1. 检查是否授予了相机权限
2. 尝试按PDA侧面的扫码按钮
3. 如果还不行，使用屏幕上的"扫码"按钮
```

### 问题3：无法登录

**解决**：
```
1. 检查PDA是否连接WiFi
2. 确认输入的手机号和密码正确
3. 尝试重启应用
```

### 问题4：扫码后没反应

**解决**：
```
1. 检查二维码格式是否正确
2. 确认网络连接正常
3. 查看是否有错误提示
```
