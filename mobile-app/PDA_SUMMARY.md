## 🎯 如何在PDA上运行

### 简单三步

#### 第1步：打包APK
```
1. 在HBuilderX中打开 mobile-app 目录
2. 菜单：发行 → 原生App-云打包
3. 选择Android，使用DCloud公共证书
4. 等待5-10分钟，下载APK
```

#### 第2步：传输到PDA
```
方法1：USB数据线连接，复制APK到PDA
方法2：通过微信/QQ发送APK到PDA
方法3：上传到服务器，PDA扫码下载
```

#### 第3步：安装运行
```
1. 在PDA上找到APK文件
2. 点击安装（允许未知来源）
3. 打开应用，授予权限
4. 登录测试（19909096066 / admin123）
5. 测试扫码功能
```
